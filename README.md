# Tablero general · O&M GPM

Portal que integra los tableros de gestión del Gasoducto Perito Francisco Pascasio Moreno (Energía Argentina – TGS).

Publicado en: https://gestionoperativa-tgs.github.io/Tablero-general/

## Agregar un tablero
Editar `index.html` y agregar una entrada en la lista `SECCIONES` (título, descripción, url, ícono y color).
